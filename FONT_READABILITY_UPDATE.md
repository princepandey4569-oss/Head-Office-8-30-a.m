# Typography Readability Update

The interface typography was increased across the login screen, navigation, dashboard cards, data tables, workload delegation views, labels, and explanatory copy.

- Explicit small UI sizes were raised to improve legibility: micro labels now use 11px, 10px copy becomes 12px, 11px copy becomes 13px, and 12–15px text is increased modestly.
- Larger display headings are retained, preserving the hierarchy of the interface.
- The existing blue/orange/violet palette and separate light/dark theme rules are unchanged.
- Responsive layout rules remain in place; please review phone-size tables and the login form in a browser after installing frontend dependencies.

The goal is to avoid using tiny text to fit more content. Where a larger label needs room, the preferred fix is to give the component more space or allow wrapping—not to shrink the type again.
