# FreshBasket AI — blue / orange / violet colour system

The interface no longer uses green as a brand or status colour. The visual identity uses cobalt and azure blues for navigation and primary actions, tangerine orange for high-attention actions, violet for AI insights, and berry red / amber for risk states. Neutral surfaces and high-contrast text keep the workspace readable in both themes.

## Usage rules

- Blue is the main navigation and primary-action colour.
- Orange highlights the most important call to action and selected operational emphasis.
- Violet identifies AI-generated explanations and decision insights.
- Red indicates critical findings; amber indicates warnings.
- Low-risk and connected states use blue/neutral styling rather than green.
- Day mode uses dark text on light surfaces; dark mode uses light text on dark surfaces.
- Avoid pale text on white, or dark text on dark panels. Verify all new components with a contrast checker.
