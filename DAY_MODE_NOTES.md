# Theme readability notes

- Day mode uses dark navy headings and slate body text on cool white surfaces, with visibly defined borders and focus rings.
- Dark mode uses near-white text and light slate secondary copy on midnight/navy-charcoal surfaces.
- Blue is the core brand colour, orange marks primary emphasis, violet identifies AI insights, and berry red/amber retain risk meaning. No green brand/status palette is used.
- Validate newly added components in both themes. Avoid low-contrast placeholders, thin pale labels, and relying on colour alone to convey status.
